# About this public snapshot

Prepared from the personal workflow template and version 0.4.0 specification.

- The original files are not modified by this publication.
- The English README, usage guide, selected design notes and worked example
  were prepared for this repository with AI assistance and have not been
  presented as original task transcripts.
- The full specification retains the core process but omits the personal host
  deployment section, old release history and historical-version dependencies.
- Configuration uses a generated workflow root instead of personal machine paths.
- A Python installer replaces the personal Bash installer for this snapshot.
- Serbian template fields and `luka.md` are retained to match existing prompts.
- Permission guidance is environment-specific; a limitation observed on one
  machine is not stated as a universal restriction of an agent.
- The experiment page summarizes questions, protocols and limitations. Private
  task rows, names, contact information and raw discussion logs are omitted.
- Portfolio generation, orchestration and host setup are outside this release.

## Referenced files

The template alone was not self-contained. It referred to `workflow.md`,
`workflow-experiments.md` and `deep_research_meta_prompt.md` in the personal
workflow root. This repository includes public versions of all three.

Private `decisions.md`, archived pilot rows, host setup notes and historical
specifications are not required to use this snapshot. Selected rationale is
summarized in `design-notes.md`. D-number references retained in the specification
are historical labels, not instructions to fetch private files.

For stronger evidence later, add a sanitized real task only after reviewing all
of its inputs and artifacts for publication. The worked example included now
illustrates the process but does not demonstrate its measured effectiveness.
